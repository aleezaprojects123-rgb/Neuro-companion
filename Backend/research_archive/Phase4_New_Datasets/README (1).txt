The file "FiguresTables_SourceData" reports the individual-subject data used to produce the figures presented in the manuscript text, as well as in Tables 1 and 2. These data also served as the input to the corresponding statistical analyses.


There are two zipped folders containing raw data from each of the two experiments reported in the manuscript. Importantly, as described in the methods of the main text, a subset of participants (n = 42; 16 children, 19 adolescents, 4 young adults, 3 older adults) whose data is included in the E1 folder completed the full Experiment 2 protocol. Thus, these participants are included in the data folders of both Experiments (and thus these data are not independent). 


Experiment 1:
Data are subdivided by experimental group (Children, Adolescents, Young adults, Older adults). Per participant one txt file is produced.

In each txt file, each line corresponds to one keypress, with the following column identifiers: 
	Column1: Run label 
	Column2: Block number
	Column3: Cue presented 
	Column4: Key pressed by the participant 
	Column7: Correct? (1=correct; 0=incorrect). 
	Column6: Response time (ms)



Experiment 2:
Data are subdivided by experimental group (Children, Adolescents, Young adults, Older adults). Per participant, 3 txt files are produced, one per experimental session. [Note the files no session specified in the file name includes Session 1 Data. e.g., Exp2_BMR-0007.txt is the Session 1 data of subject 0007. Exp2_Session2_BMR-0007.txt is the Session 2 data of subject 0007.
